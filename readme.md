# 🛒 Responsive Shopping Cart Web Application

## 🎯 AIM

To create a **responsive shopping cart web application** using HTML, CSS3, Flexbox, and Grid for effective layout design. The application includes registration, login, product catalog, and shopping cart pages.

## 📝 DESCRIPTION

This project focuses on developing a responsive shopping cart web application using **HTML, CSS, and JavaScript**. It allows users to register, log in, browse a product catalog, add items to the shopping cart, and view the cart contents.

CSS3 features such as **Flexbox and CSS Grid** are used to design structured and responsive layouts. The application is designed to be mobile-friendly and adapts seamlessly to different screen sizes, providing a consistent user experience across devices.

## ✨ KEY FEATURES

- 👤 **User Registration** — Provides a registration page for users.
- 🔐 **User Login** — Includes a login page for user access.
- 🛍️ **Product Catalog** — Displays a collection of products for browsing.
- 🛒 **Shopping Cart** — Allows users to add items and view cart contents.
- 📱 **Responsive Design** — Adapts the layout to different screen sizes.
- 🎨 **Modern Layout Design** — Uses CSS3, Flexbox, and Grid for styling and layout management.

## 🛠️ TECHNOLOGIES USED

- 🌐 **HTML5** — Structures the web pages.
- 🎨 **CSS3** — Styles the application and creates responsive layouts.
- 📐 **Flexbox & CSS Grid** — Organize page elements and product layouts.
- ⚙️ **JavaScript** — Adds client-side functionality and form validation.

## 📱 RESPONSIVE DESIGN

The application uses CSS3 layout techniques, including Flexbox and Grid, to create a flexible and mobile-friendly interface. These features help organize content efficiently and allow the layout to adjust to different screen sizes.

## 🎓 OBJECTIVE

The main objective of this project is to understand and implement the fundamentals of responsive web development by combining HTML, CSS3, Flexbox, Grid, and JavaScript to build a multi-page shopping cart interface.
